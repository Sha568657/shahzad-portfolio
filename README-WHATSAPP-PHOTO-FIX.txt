IMPORTANT: Is version ko direct index.html par double-click karke use na karein. Admin settings aur website ko ek hi browser origin chahiye, warna photo refresh ke baad website par apply nahi hoti.

1. ZIP ko Extract All karein.
2. Folder ke andar START-WEBSITE.bat par double-click karein.
3. Jo black command window khule, usay band na karein.
4. Browser mein http://127.0.0.1:4173 khul jayega.
5. Admin Panel: http://127.0.0.1:4173/admin.html
6. Login karein, Profile photo > Choose photo se image select karein.
7. Preview aane ke baad neeche Save Changes dabayein.
8. Homepage tab par Ctrl+F5 dabayein.
